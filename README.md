# 🚆 Транзит (Transit) — Пассажирский портал вокзала

Современное веб-приложение для пассажиров, позволяющее искать расписание поездов, отслеживать статус ожидания и ориентироваться на территории вокзала с помощью интерактивной карты.

## 🚀 Основные возможности

- 🔍 **Поиск билетов:** Удобный выбор станций отправления и назначения, даты и времени.
- 🚉 **Карточки рейсов:** Отображение найденных маршрутов с ключевой информацией.
- ⏳ **Страница ожидания:** Информационный экран для пассажиров, ожидающих посадку.
- 🗺️ **Интерактивная навигация:** SVG-карта вокзала с визуализацией маршрута между точками (вход, залы, платформы).
- 📱 **Адаптивный дизайн:** Mobile-first подход, корректное отображение на всех устройствах.

## 🛠 Технологический стек

- **Фреймворк:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS v3](https://tailwindcss.com/)
- **UI-компоненты:** [shadcn/ui](https://ui.shadcn.com/) (на базе [Radix UI](https://www.radix-ui.com/))
- **Иконки:** [Lucide React](https://lucide.dev/)
- **Управление состоянием:** React Context API

## ⚙️ Начало работы

### Предварительные требования
- Node.js (версия 18.x или выше)
- Менеджер пакетов: `npm`, `yarn`, `pnpm` или `bun`

### Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   cd transit-app
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки (с использованием Turbopack):
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.

### Сборка для продакшена
```bash
npm run build
npm run start
```

## ⚠️ Важные примечания для разработчиков

1. **Tailwind CSS v3:** Проект намеренно использует Tailwind CSS v3 для обеспечения максимальной стабильности в связке с Next.js 16 и Turbopack. 
   - *Примечание:* Пакет анимаций `tailwindcss-animate` используется вместо `tw-animate-css` (который предназначен для v4), чтобы избежать предупреждений компилятора (`Unknown at rule: @theme`) и проблем со сборкой.
2. **Архитектура хедера:** Компонент `<TopHeader />` вынесен в файл `src/app/(passenger)/layout.tsx`. Убедитесь, что в файлах отдельных страниц (например, `page.tsx`) **нет** дублирующих тегов `<header>`, чтобы избежать наложения интерфейсов.
3. **Кнопка "Назад":** На всех вложенных страницах используется единый стиль кнопки возврата: белый круг с тенью и иконкой `ArrowLeft` из `lucide-react`.
